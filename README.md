# David's Dotfiles

## Instructions

Clone the repository. Then, run `install.sh`.

```
$ git clone git@github.com:davidfcohen/config.git
$ cd config
$ ./install.sh
```

Optionally, create symbolic links manually.

```
$ ln -sn $(pwd)/alacritty $HOME/.config/alacritty
```

## Locations

| Program        | Config Location       |
| -------------- | --------------------- |
| `alacritty`    | `~/.config/alacritty` |
| `fish`         | `~/.config/fish`      |
| `helix`        | `~/.config/helix`     |
